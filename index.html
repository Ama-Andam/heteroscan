🔬About HeteroScan
What is HeteroScan?
HeteroScan is a post-infection malware behavioral analysis system built for academic research. It combines three technologies: dynamic sandbox analysis via CAPE, heterogeneous graph neural networks (HAN), and large language model explanation via Claude. It addresses two key gaps in existing malware analysis research — the representation gap and the ground truth gap.

Heterogeneous Graph Node Types
⚙️
Process Nodes
Each process observed during execution. Spawns edges connect parent to child processes.
📞
API Call Nodes
Windows API functions called by processes. The primary behavioral signal for detection.
📄
File Nodes
Files read or written during execution. Persistence mechanisms often involve file system changes.
🔑
Registry Nodes
Registry keys accessed. Malware commonly writes to Run keys for persistence.
🌐
Network Nodes
Network endpoints contacted — C2 servers, exfiltration targets, update servers.

7 Edge Types
spawns, calls, reads_file, writes_file, reads_reg, writes_reg, connects — typed relationships.

Research Context
This system is part of a master's thesis at the University of North Dakota titled "Malware Detection and Behavioral Analysis in IoT Environments: A Multi-Study Deep Learning Approach." Study 3 specifically addresses post-infection behavioral analysis using heterogeneous GNNs. The model is trained on 600+ samples across 20+ malware families including AsyncRAT, XWorm, njRAT, RedLine, AgentTesla, Vidar, Formbook, and more.
❓Help & Documentation
How to Analyze a Sample
1. Drag and drop a Windows executable (.exe, .dll) onto the upload zone, or click Browse File to select one from your computer.

2. Click Analyze Sample to submit it to the CAPE sandbox. The file executes in an isolated Windows 10 virtual machine.

3. Wait 3–5 minutes for sandbox execution and behavioral report generation.

4. HeteroScan automatically builds a heterogeneous behavioral graph, runs GNN inference, and generates an LLM explanation.

5. Review the verdict, behavioral graph visualization, graph statistics, network connections, and AI-generated analysis report.

Understanding the Verdict
The MALICIOUS / BENIGN verdict is produced by a Heterogeneous Graph Attention Network (HAN) trained on behavioral graphs from 600+ analyzed samples. The confidence score reflects model certainty — scores above 95% indicate strong behavioral evidence, while 70–95% suggests suspicious but not definitive patterns.

The GNN operates on the structural properties of the behavioral graph, not on signatures or hashes. This means it can detect previously unseen malware variants that exhibit known behavioral patterns.
Graph Visualization Guide
The behavioral graph shows relationships between entities observed during sandbox execution:

🟠 Orange = Process nodes
🔵 Blue = API call nodes
🟢 Green = File nodes
🟣 Purple = Registry key nodes
🔴 Red = Network endpoint nodes

Node size reflects the count of that entity type. Edges between the central process node and surrounding nodes represent behavioral relationships.
Safety & Privacy
⚠️ HeteroScan executes uploaded files in an isolated sandbox environment with no internet access. Do not upload files containing sensitive personal information. All execution happens in a network-isolated Windows 10 VM. Uploaded samples are used solely for behavioral analysis and are not shared externally.
