          About HeteroScan

          A post-infection behavioral analysis system built for academic research.

          How It Works

          1. Sample UploadA Windows PE executable is submitted through this page.
          2. CAPE SandboxThe sample runs in an isolated Windows 10 virtual machine while CAPE records its processes, API calls, file and registry activity, and network traffic.
          3. Graph BuilderThe trace becomes a heterogeneous graph, with a typed node for each entity and a typed edge for each action.
          4. Ensemble ClassifierRandom Forest, Extra Trees and XGBoost vote on structural features of the graph to produce the verdict and confidence.
          5. LLM ExplanationA large language model reads the evidence and writes the report shown with each result.

          Graph Node Types

          Process
          Each process observed during execution. Spawn edges link parents to children.
          API Call
          Windows API functions called by processes, the main behavioral signal.
          File
          Files read or written. Persistence often shows up here.
          Registry Key
          Keys accessed. Malware commonly writes to Run keys to survive reboots.
          Network
          Endpoints contacted, such as C2 servers and exfiltration targets.

          Seven typed edges connect them: spawns, calls, reads_file, writes_file, reads_reg, writes_reg and connects.

          Reading the Verdict

          The verdict comes from a voting ensemble of Random Forest, Extra Trees and XGBoost classifiers trained on structural features of behavioral graphs. Confidence reflects how strongly the ensemble agrees.

          Because the classifier reads graph structure rather than signatures or file hashes, it can flag new variants that behave like known families.

          MITRE ATT&CK Techniques It Looks For

          • T1055Process InjectionNtProtectVirtualMemory and LdrLoadDll call patterns in the graph.
          • T1547Boot or Logon AutostartWrites to the HKCU and HKLM Run registry keys.
          • T1059Command and Scripting InterpreterSpawn edges to cmd.exe and powershell.exe.
          • T1071Application Layer Protocol (C2)Connections to non-standard ports and unknown hosts.

          Analyzing a Sample

          1. Add a FileDrop a Windows executable (.exe or .dll) on the upload area, or click it to choose one.
          2. Start the RunPress Analyze sample. The file goes to the CAPE sandbox and runs in an isolated virtual machine.
          3. Wait for the ReportThe progress tracker shows each stage. A run takes a few minutes.
          4. Review the ResultRead the verdict, the behavior graph, the indicators and the AI-generated explanation.

          If the status pill says offline, the sandbox is not running right now. The four finished reports still work.

          Go to Analyze

          Safety and Privacy

          Samples run in an isolated Windows 10 virtual machine.

          Do not upload files that contain personal or sensitive information.

          Uploaded samples are used only for behavioral analysis and are not shared.
